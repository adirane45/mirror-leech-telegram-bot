🚀 DEPLOYMENT INSTRUCTIONS
================================================================================

OPTION 1: Docker (Recommended)
  1. Clone repo
  2. cd mirror-leech-telegram-bot
  3. Copy and edit: cp config/.env.production.example config/.env.production
  4. Update: BOT_TOKEN, TELEGRAM_API, TELEGRAM_HASH, OWNER_ID
  5. Deploy: docker compose up -d --build
  6. Verify: docker compose ps (all Up)
  7. Test dashboard: http://localhost:8060

OPTION 2: Manual
  1. Python 3.13+ with venv
  2. pip install -r config/requirements.txt
  3. Start Redis, Aria2, qBittorrent separately
  4. Configure .env.production
  5. python -m bot

OPTION 3: Testing Without Deployment
  1. python -m pytest tests/ -q -o addopts=""
  2. All 497 tests should pass
  3. Verify Phase 10 & 11 tests: 6+6 passing
